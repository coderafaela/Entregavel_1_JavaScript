# Entregável_2 – Algoritmos em JavaScript

Repositório desenvolvido no **WebStorm** contendo a implementação de seis algoritmos clássicos em **JavaScript**, como parte do projeto **Entregável_1**, uma aplicação web.

## 📋 Descrição

Este repositório reúne a implementação dos seguintes algoritmos:

| Algoritmo | Descrição |
|---|---|
| **Número é primo** | Verifica se um número inteiro positivo `n` é divisível apenas por 1 e por ele mesmo. |
| **Somatório** | Calcula a soma de um conjunto de números informados pelo usuário. |
| **Fibonacci** | Gera a sequência de Fibonacci (0, 1, 1, 2, 3, 5, 8, 13...) para `N > 1` termos. |
| **Máximo Divisor Comum (MDC)** | Calcula o maior número inteiro que divide simultaneamente dois números `a` e `b`, utilizando o algoritmo de Euclides. |
| **Ordenação (Quicksort)** | Ordena um array de números utilizando o método Quicksort. |
| **Contagem** | Dado um conjunto de `N` valores, conta quantos deles são maiores ou iguais a 50 (aprovações). |

## ▶️ Como executar

Os scripts utilizam `prompt()`, e `console.log()`, portanto devem ser executados em um **ambiente de navegador** (não em Node.js puro, que não possui essas funções nativas).

**Opções para execução:**

1. **Abrindo em um navegador**
   - Crie um arquivo `.html` simples que importe o script desejado via `<script src="arquivo.js"></script>`.
   - Abra o `.html` no navegador e utilize o Console do DevTools (F12) para acompanhar as saídas.
